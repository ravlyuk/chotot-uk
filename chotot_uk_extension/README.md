# Chợ Tốt → Українська

Розширення Google Chrome, яке перекладає [Chợ Tốt](https://www.chotot.com/) українською — зокрема [xe.chotot.com](https://xe.chotot.com/) і сторінки пошуку на www.chotot.com.

- Словник для меню, категорій, фільтрів, часу та типових фраз оголошень
- Онлайн-переклад довгих описів (можна вимкнути в попапі)
- Стежить за динамічним контентом і зміною URL без перезавантаження

## Встановлення / оновлення

1. Відкрийте `chrome://extensions`
2. Увімкніть **Режим розробника**
3. Якщо вже завантажено: натисніть **Reload** на картці розширення
4. Інакше: **Load unpacked** і оберіть теку `chotot_uk_extension`
5. Оновіть вкладку Chợ Tốt (`www.chotot.com` або `xe.chotot.com`)

Android-обгортка (WebView): див. [`../chotot_uk_android/README.md`](../chotot_uk_android/README.md).
